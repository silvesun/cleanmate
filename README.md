# SafeSweep website

Public pages for the SafeSweep Mac app, served with GitHub Pages at <https://silvesun.github.io/cleanmate/>.

| Page | Chinese | English | App Store Connect field |
|---|---|---|---|
| Home | `index.html` | `en/index.html` | Marketing URL (optional) |
| Support | `support.html` | `en/support.html` | Support URL (required) |
| Privacy Policy | `privacy.html` | `en/privacy.html` | Privacy Policy URL (required) |

Plain HTML and CSS with system fonts only: no scripts, analytics or third-party requests, matching the privacy policy.
When the app's data handling changes, update both privacy pages and their effective date before releasing that version.
